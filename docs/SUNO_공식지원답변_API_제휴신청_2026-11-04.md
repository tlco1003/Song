# Suno 지원 답변 반영 — SONG API·B2B 제휴·Voices 신청 지침 (2026-11-04)

> **근거:** SONG 프로젝트 운영자가 전달한 Suno 고객지원 이메일 원문(발신 내용 끝에 "This reply was generated by Suno's AI support assistant, which can make mistakes." 명시). **AI 지원 안내이므로 법적 계약·개발자 권한 승인·Suno 담당자의 확답과 동일하지 않다.**  
> **이 문서는 기존 `docs/IMPLEMENTATION.md` 및 `docs/SUNO_API_MCP_VOICES_내목소리_연동지시서.md`의 상업화 해석을 보완하고, 상충하면 이 문서의 최신 신청·승인 상태를 우선한다.**

## 1. Suno 측 답변으로 새로 확인된 사항

1. **일반 소비자 계정을 위한 셀프서비스 공개 개발자 API는 현재 없다.** `platform.suno.com`은 플랫폼 로그인 화면이 존재하지만 일반 유료 구독자가 로그인했다고 **API 키 발급·문서 접근 권한이 자동 생성되는 게 아니다.** 접근 오류를 소비자 계정의 버그로 단정하지 않는다.
2. 정식 개발자/API 사용에 대한 **관심 신청 폼**: **https://sunomusic.typeform.com/apiform**. 신청은 관심 표명일 뿐이며 승인·회신·제공 일정은 보장되지 않는다.
3. **B2B·상업용 통합 / 라이선스 제휴를 검토**한다. 지원 이메일 **support@suno.com** 에 SONG의 구체적 구현 형태, 수익모델, 일정, 필요한 기술 범위를 답신하고 관련 검토 부서 연결을 요청한다.
4. **Suno MCP Beta (`https://api.suno.com/mcp`)는 ChatGPT·Claude 같은 AI 어시스턴트 안에서 개인 창작을 하기 위한 연동**이라고 Suno 지원 답변에서 명시했다. **제3자 고객용 SONG 제품에 바로 제공하는 공식 API 권한으로 해석하지 않는다.**
5. **Suno Voices는 운영자 Pro 계정에서 suno.com으로 직접 이용 가능**하다. 그러나 REST API / MCP 계약에 Voices 기능(신규 등록, 본인 확인, 선택, 가창)이 포함되는지 **미확정**이며 **제휴 계약 검토 대상**이다.
6. Suno의 해당 이메일은 **AI 지원 어시스턴트 생성**이라는 주의 문구를 동반한다. 계약과 지원 기능은 **사람인 담당자/서면 공식 계약**으로 재확인해야 한다.

## 2. 반드시 구분할 기능과 승인 상태

| 기능/권리 | 개인 Suno 계정 | 제3자 SONG 유료 웹앱 |
|---|---|---|
| GPT가 고객 사연을 가사로 편집 | SONG의 OpenAI API 코드 사용 가능(계정 키·정책 필요) | SONG 자체 서비스 구현 가능 |
| Suno에서 음악 제작 | Suno UI에서 가능, Suno MCP 개인용 연동 가능 | **Suno 별도 B2B/API 승인 필요** |
| Suno Voice 등록/검증 | 본인 계정에서 가능 | **Voice 등록·본인 확인 REST/MCP 스키마와 계약 모두 미확인** |
| 등록 Voice를 노래에 사용 | 본인 Suno UI 및 개인 MCP 제품 소개 | 제3자 고객의 Voice 선택·생성 API 범위 **미확정** |
| 고객 주문곡을 상업적으로 제작·판매 | 일반 유료 이용권의 곡별 상업 권리와 별도 조건 확인 | **서비스 제공·API 통합·재판매·고객 Voice 처리 서면 계약 필수** |
| 외부 앱 자동 OAuth·결제·생성 | 개인 어시스턴트 MCP 로그인에 제한 | **정식 제휴에서 인증/멀티테넌시/과금 합의** |

## 3. SONG의 최종 목표 — 기능 명세(허가 전에는 구현 승인으로 간주 금지)

**고객 입력:** 기존 다섯 질문 `recipient`, `memory`, `message`, `gratitudeApology`, `occasion`을 유지. 상대 나이대 `recipientAgeGroup`, 관계 `relativePosition`, 평소 말투 `speechStyle`, `genre`, `mood`와 길이를 선택. 반말/존댓말은 나이 고정값으로 처리하지 않는다.

**작사:** OpenAI GPT로 편지처럼 말하는 기승전결, 내 감정의 회상·자문(그랬었어/그랬네/그랬을까), 상대의 행동에 대한 감사, 속마음의 조심스러운 헤아림, 절제된 꾸밈어로 가사 생성. 사용자가 편집·확정.

**작곡:** Suno와 별도 합의된 공식 B2B API 계약으로 가사·Style of Music을 전달하고 음악 생성. 개인용 MCP를 서버 자동 재판매 수단으로 사용하지 않음.

**개인 목소리:** 사용자의 명시적 동의 + **실제 목소리 소유자의 직접 본인 인증** + 별도 허가된 Voice 등록·선택 API가 확인되는 경우에만 활성화. 타인의 음성을 대신 등록하거나 동의만으로 본인 인증을 우회하지 않는다. API가 없다면 개인 Suno 앱에서 직접 Voice 생성/확인하도록 안내하고 자동 업로드는 미지원 표시.

**음원 결과:** 실제 호출 응답, Suno 생성곡 ID·URL, 사용 Voice 여부, 한국어 가사 일치, 재생·상업 다운로드 조건을 검증하고 상태를 `verified` / `unverified`로 구분. AI 프롬프트를 전달한 것만으로 품질 보장·완료 아님.

## 4. Suno에 제출할 구체적 사업 내용 (복사 가능한 영문 초안)

**Project:** SONG — Personalized Story-to-Song Gift Platform

**Description:** SONG is a consumer-facing personalized music-gifting web application. Customers answer five short questions about a recipient, shared memories, gratitude or apologies, and the occasion. OpenAI GPT turns those details into an original Korean lyric in a natural, letter-like style, with a clear emotional arc and user approval before music generation. We would like to integrate Suno under an explicitly authorized commercial API agreement to turn the approved lyrics and musical style into songs.

**Optional voice experience:** We would also like consenting users to sing in their own voice through Suno Voices, with identity/ownership verification performed through Suno-approved mechanisms. We will not clone someone else's voice without the actual voice owner's verified participation and authorization.

**Business model:** Paid personalized song orders and optional add-on for verified own-voice singing. We are exploring a proof-of-concept before public launch. We have not committed to a launch date or production volume.

**What we seek from Suno:** Developer/B2B API eligibility, commercial authorization for embedded music generation and downstream customer delivery, supported lyric/style control, voice registration and verification, choosing a verified Voice during generation, per-user OAuth/account requirements, music output licensing and downloads, pricing/credit billing, capacity limits, privacy and deletion policies.

**Proof of concept:** We can share original songs generated on the founder's personal Pro account and a functional web application prototype. No claim of confirmed API access or third-party commercial authorization.

**Next step requested:** Please route SONG to a human API/partnership reviewer and tell us whether a commercial integration agreement can cover this use case.

## 6. 현재 코드 안전상태/정정

`src/providers.mjs` 와 `src/server.mjs` 에 **공식 Suno MCP를 개인 개발 환경에서 호출할 수 있도록 시도한 프로토타입 경로**가 있지만, 이는 **상업용 API 통합 승인, Suno OAuth 로그인 완료 또는 실제 음원 생성 성공을 뜻하지 않는다.** 해당 경로를 고객용 제품 배포의 API로 간주하지 말 것. 로그인 확인 후 서버에 아무 토큰을 넣어도 자동으로 제휴 권리가 생기는 것은 아니다.

**권장 기술 결정:** 프로덕션 Suno provider는 `status:blocked_pending_b2b_agreement` 으로 관리. 추후 B2B 승인 받은 공식 문서와 정확한 인증/Voice 스키마가 주어지면 전용 어댑터를 구현하고 실제 생성·법적 사용 권한을 검증한다. 개인 MCP 테스트 경로는 프로덕션과 분리한다.
