# WITHU 사전 체험 — 30초 음악, 얼굴 자료, 모바일 셀프 녹화

기준일: 2026-11-05 (KST) / 고객 페이지: `docs/checkout.html` / 코드: `docs/checkout-media.js`

## 실제 구현된 고객 기능

1. `docs/prices.json`의 금액을 `docs/checkout.js`에서 조회·표시
   - 맞춤 노래 1곡: 29,000원 (고정 표시 가격)
   - 맞춤 노래 2곡: 39,000원 (고정 표시 가격)
   - 노래 + 뮤직비디오: **300,000원부터** (제작 범위 협의·최종 견적 필요)
   - **PG 결제는 아직 비활성화**. 가격 표시는 결제 승인이나 서비스 제공 약속이 아니다.
2. 오디오 30초 미리 듣기:
   - 공개 `docs/media/tracks.json` 목록에서 MP3 예시곡 선택, 30초 자동 종료, 일시정지·처음부터.
   - 파일 선택으로 이 기기에 보관된 MP3/M4A/WAV/OGG도 30초 미리듣기 가능 (100MB 이하).
   - 고객의 사연을 방금 넣어 새로 생성한 곡의 30초 미리듣기가 아니다. 그 기능은 정식 B2B 작곡 API가 마련된 이후에만 가능하다.
   - 현재는 **UI 시간 제한**이다. 공개 저장소에 올라 있는 원곡 MP3 자체는 공개되어 있으므로 DRM이나 30초 외 재생의 기술적 차단이 아니다. 상용 유료 미리 듣기는 서버에서 **원곡을 30초짜리 별도 파일로 인코딩해 공개**하고, 완성곡은 인증된 개인용 스토리지의 만료 서명 URL에서 제공해야 한다.
3. 영상 상품(`audio_video`)을 선택한 경우에만 노출되는 얼굴·영상 입력:
   - 사용자 또는 동의받은 출연자의 **얼굴 사진** 1개 (15MB 이하) → 이미지 미리보기 및 무대 배경 콘셉트에 정지 이미지 삽입.
   - **얼굴·표정 영상** 1개 (200MB 이하) → 업로드 직후 브라우저 내에서 영상 재생.
   - 아이폰 기본 카메라 촬영: `<input type="file" accept="video/*" capture="user">` 기본 촬영 화면으로 이동할 수 있는 대체 경로.
   - WITHU 내 실시간 카메라: `getUserMedia({video:{facingMode:'user'},audio:true})`, 오류 시 무음 영상 재요청, `MediaRecorder`로 직접 30초 내 촬영. MPEG-4 또는 WebM 등 브라우저가 지원하는 형식 자동 탐지.
   - 카메라 켜기 / 녹화 / 종료 / 끄기, 재생 미리보기, 삭제 버튼, 상품 변경·동의 취소·페이지 종료 시 스트림 정리.
   - 본인 또는 출연자 명시적 동의가 없으면 사진·영상 등록·카메라 켜기를 막도록 설계.

## 직접 시험하는 웹 주소

- 일반 주문·음악 미리듣기: `https://tlco1003.github.io/Song/checkout.html`
- 뮤직비디오 상품과 얼굴/카메라 기능을 바로 확인: `https://tlco1003.github.io/Song/checkout.html?product=audio_video#video-media-section`
- 홈페이지: `https://tlco1003.github.io/Song/`, 이어지는 **30초 음악 · 얼굴 영상 체험** 링크.

카메라는 **HTTPS 또는 localhost**가 필요하며 브라우저의 카메라·마이크 권한 허용이 필요하다. 아이폰에서는 Safari에서 열어 권한을 허용한다. iOS WebView/ChatGPT 앱 내부 미리보기는 권한 동작이 제한될 수 있으니 Safari에서 직접 확인한다. 녹화 결과 컨테이너는 브라우저에 따라 `.mp4` 또는 `.webm`이 될 수 있다.

## 중요한 미구현 / 보안 경계

- 얼굴 교체(faceswap), 노래 립싱크, 실제 GPU 작업 실행, 가수 영상 다운로드 파일 생성은 **아직 미구현**. ‘무대 콘셉트 미리보기’는 고객 얼굴 이미지를 배경에 단순 배치한 시안이며 가수로 바꾼 영상이 아니다.
- 입력 사진·얼굴 동영상·녹화 결과는 브라우저의 `URL.createObjectURL`로만 재생한다. 외부 서버 요청, 원본 서버 업로드, 결제 정보 전송, 데이터베이스 저장, 이메일 전송 모두 없음. 페이지를 벗어나면 URL을 해제한다.
- 현재 서버 코드는 `GET /api/commerce/readiness`가 결제 불가를 반환하며 주문·결제 POST는 503으로 차단한다.
- 실제 상업화에는 PG 승인 검증, 고객별 인증 및 비공개 업로드, 동의 철회·삭제, 음원/얼굴 처리 비용 계산, 저작권·초상권 검증, 생성 상태 추적, 이메일 발송, 실패 환불 및 품질 보장 검증이 필요하다.
- 상업용 얼굴 모델·보컬 모델의 라이선스와 Suno B2B 계약이 확인되기 전에는 유료 자동 제작이 가능한 것으로 표시하지 않는다.
