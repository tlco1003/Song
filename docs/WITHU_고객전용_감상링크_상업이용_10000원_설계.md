# WITHU 고객 전용 음악 감상과 상업적 이용 추가 결제

## 적용한 화면
- 기본 상품은 1곡 29,000원 / 2곡 39,000원: 맞춤 제작 후 전용 웹 링크로 감상한다. 원본 MP3 파일이나 상업적 이용 허락은 포함하지 않는다.
- 제작자가 정한 정상가 1곡 100,000원 / 2곡 200,000원은 회색 취소선으로 표시한다. 과거 판매가라고 주장하지 않는다.
- 결제 페이지에서 수령 이메일을 입력하면, 실제 제작·결제·메일 시스템이 설치된 후 고객에게 인증된 상세 화면 링크를 보내는 구조다.
- 공개 예시 음원의 다운로드·커버 받기 UI는 숨겼다.
- 고객 전용 상세 페이지는 기존 song.html을 재사용한다. 2곡 구매 시 최종 선정한 두 음원 사이를 전환하고 반복해서 감상할 수 있도록 프런트엔드 처리했다.

## 개별 링크 보안
- 최종 선정곡, 원주문 PG 확인, 고객 수령 이메일 확인이 모두 완료된 후 256비트 난수 토큰 발급.
- 이메일 링크 형식: HTTPS 사이트의 song.html 주소에 delivery 프래그먼트를 붙인다. URL 검색 파라미터로 주문번호나 이메일을 노출하지 않는다.
- 서버 DB에 토큰 원문 대신 SHA-256 해시 저장. 이메일 발송에는 원문 링크만 사용.
- 사이트에서 POST /api/delivery/resolve로 토큰을 제출하고, 서버가 주문 및 수령자 확인 후 HttpOnly 세션 쿠키를 발급.
- GET /api/delivery-assets/{티켓}은 매 요청마다 인증·결제 및 최종 선정된 곡인지 검증. 비공개 저장 경로는 GitHub 저장소 및 웹 루트 바깥의 WITHU_PRIVATE_MUSIC_DIR.
- 음원을 브라우저에서 재생시키면 기술적으로 녹음·복사를 완전히 막을 수는 없다. UI에 다운로드 버튼이 없다는 것은 보호된 원본 파일을 직접 제공하지 않는다는 의미다.

## 원본 음원 + 상업적 이용 허락 옵션
- 추가 금액 10,000원, 별도 결제, 주문당 1회. 2곡 주문이라면 최종 선택된 2곡 모두 권리 확인 대상.
- 이 금액은 최초 주문 금액에 자동 합산하지 않는다.
- 권리 검증 시 제공자 상업적 이용 허가, 공식 다운로드 기록, 원곡/리믹스 구분, 제3자 저작물 허락, 고객에게 비독점 상업적 이용 허락을 부여할 권한을 확인한다.
- 해당 옵션의 별도 PG 결제가 10,000원으로 실제 승인되어 DB에 원자적으로 기록된 고객에게만 다운로드 전용 티켓을 제공한다.
- 구매 버튼은 권리 검증과 실제 PG가 연결되기 전에는 비활성 상태로 두며, 기본 감상권으로는 파일을 받을 수 없다.

- 이 내용은 코드 검증 기준이며 실제 계약상 권리 부여 범위를 별도로 확인해야 한다.

## 배포를 위해 아직 연결해야 할 것
- PG 주문 DB 및 실결제 확인/환불
- 고객 이메일 인증·전용 링크 발송
- 원본 음원 비공개 저장소 및 권리 증빙 원장
- HttpOnly 쿠키 발행/검증과 링크 만료·재발급
- 상업적 이용권 약관/동의 및 별도 PG 결제 결과 검증
- 제작 완료곡의 운영자 검수·최종 선별과 고객 감상 링크 발급

현 시점에는 자동 PG, 고객 DB, 메일 발송기, 파일 저장소 및 권리 증빙 어댑터가 없다. 따라서 공개 사이트의 자동 주문·권리 결제는 실제로 동작한다고 주장할 수 없다. 서버가 없는 경우 API는 503으로 실패한다.
