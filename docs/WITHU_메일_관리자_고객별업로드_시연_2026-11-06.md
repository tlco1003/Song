# WITHU 이메일·관리자 고객별 업로드·만원 옵션 실험

작성: 2026-11-06 / 저장소: tlco1003/Song / main

## 공개 시연 링크

- 고객에게 발송할 이메일 디자인: https://tlco1003.github.io/Song/email-preview.html
- 이메일을 열고 고객 노래를 감상하는 화면: https://tlco1003.github.io/Song/my-music-preview.html
- 운영자 고객별 주문·음원/가사 등록 화면: https://tlco1003.github.io/Song/admin.html

위 링크는 공개 화면 미리보기이며, 실제 고객의 개인 정보나 구매곡을 포함하지 않는다.
공개 관리자 페이지에서는 관리자 비밀키 입력 및 데이터 제출이 비활성화되어 있다.

## 로컬 관리자 시험 실행 (Node.js, OpenSSL 필요)

~~~bash
git clone https://github.com/tlco1003/Song.git
cd Song
export HOST=127.0.0.1
export PORT=3000
export WITHU_STAGING_ENABLED=true
export WITHU_STAGING_ADMIN_KEY="$(openssl rand -hex 32)"
export WITHU_PRIVATE_MUSIC_DIR="$(mktemp -d -t withu-private-test-XXXXXX)"
printf '%s\n' "$WITHU_STAGING_ADMIN_KEY"
npm run staging
~~~

로컬 주소: http://127.0.0.1:3000/admin.html

1. 로컬 관리자 키로 접속해 테스트 고객의 이메일, 연락처, 상품, 장르와 사연을 등록한다.
2. 고객별 주문함에서 해당 주문을 선택하고 관리자 **모의 결제완료**를 실행한다.
3. 선택한 고객 주문에 MP3/M4A/WAV 1~2곡을 올리고, 곡 제목과 가사를 각각 입력한다.
4. 제작 완료 및 개인 감상 링크를 발급한다. 파일은 GitHub 공개 저장소 밖의 로컬 비공개 폴더에 저장한다.
5. 모의 발송함의 개별 링크로 나의 노래함에 들어간다. 그 주문의 음악만 보여야 한다.
6. 공유된 링크도 동일 주문에 대한 접근으로만 사용하고, 다른 고객의 주문과 음원은 차단한다.
7. 관리자 모의 10,000원 추가 결제로 다운로드 화면을 시험할 수 있다. 테스트 상태일 뿐 실제 금전 거래나 상업적 이용권이 아니다.

로컬 테스트 주문과 링크는 재시작 시 사라진다. 링크의 수명도 제한되어 있으며 실제 서비스에서는 갱신 및 회수 정책을 구현해야 한다.

## 실제 메일 발송 확인 결과

- 테스트 수신 주소는 대화에서 제공받았으며, 공개 저장소 코드에는 하드코딩하지 않는다.
- 연결된 Gmail 계정으로 실제 테스트 메일 발송을 두 번 시도했으나 도구 측 INVALID_ARGUMENT: GmailApiError: Failed to send email 오류로 거절되었다.
- 메일 초안 생성도 같은 방식으로 실패했다. 제공사에서 구체 원인을 반환하지 않아 원인은 미확정이다.
- 실제 발송 성공, Naver 받은편지함 수신 및 개인 주문 접근은 **검증되지 않았다**. 공개 이메일 미리보기는 수신 증거가 아니다.
- 운영용 Resend 발신 도메인 인증, RESEND_API_KEY, WITHU_FROM_EMAIL과 실 서버 구성 후 이메일 실발송 시험이 필요하다.
- 서버 Resend 어댑터는 고객 개인 HTTPS 링크를 인라인 HTML 및 일반 텍스트로 동시 전송하도록 구현했다.
- Resend의 signed webhook email.sent/delivered/bounced 검증 함수는 이미 마련되어 있다.

## 향후 운영 연결

- 실제 PG 결제와 고객/주문/음원 DB, 주문 소유권을 검증하는 API.
- 인증된 관리자 화면의 결제 내역 조회 및 고객별 음원/가사 입력과 배포.
- 영속 비공개 파일 저장소, 이메일/문자/카카오 알림톡 전송과 반송 재시도.
- 만원 상업적 이용 허락의 실제 라이선스/권리 검증과 별도 PG 결제.
- Suno 사업용 생성 API 연결 전에는 결제 확인 주문을 관리자에게 알리고 직접 제작 후 업로드한다.
