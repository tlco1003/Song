# WITHU — 음악 스타일 프롬프트의 비공개 서버 저장소와 역사적 근거 데이터

작성: 2026-11-05
상태: **구조 구현, 전체 장르·시대·대표곡 근거 수집 및 제작 레시피 구축은 미완료**

## 고객에게 노출할 것과 노출하지 않을 것

- **고객에게 노출**: 선택 가능한 7개 장르, 6개 분위기, 1960~2020년대/자동/상관없음 시대 옵션, 받는 사람 나이대와 관계, 개인 사연, AI가 생성한 가사 미리보기, 상품 구성과 가격.
- **고객에게 비노출**: 원본 음악 지시 프롬프트, 악기/보컬 엔진 파라미터, 자체 스타일 MD, 시대별 근거별 음악 설계, 외부 음악 생성 모델 호출 매핑, 제공자 API 키, 운영자 작업 흐름.
- 현재 브라우저에는 `docs/music-genres.json`의 **장르 ID·레이블만** 제공한다. 프롬프트는 `src/music-style-library.mjs`에서 서버 실행 시 합성하고 `src/song-production-plan.mjs`에서 주문별 곡 수만큼 계획한다.
- **중요:** `tlco1003/Song`은 공개 저장소이다. 이 저장소에 저장한 `src/` 파일과 MD 파일은 GitHub 방문자가 읽을 수 있다. 코드가 브라우저 번들에 없다는 것과 GitHub에서 비공개라는 것은 **다르다**. 독자적인 악기 배합·편곡 프롬프트 원본과 가사 정책은 반드시 비공개 저장소/서버 볼륨으로 이동한다. Git 기록에 한 번 공개한 내용은 나중에 파일을 지워도 이전 커밋에 남을 수 있다.

## 운영 서버가 읽을 비공개 파일 계약

`WITHU_PRIVATE_STYLE_DIR` = 공개 GitHub Pages 또는 public `docs/` 바깥의 보호된 절대경로.

예: `/srv/withu-private/styles` (설정 예시일 뿐 실제 서버가 존재하거나 마운트된 것은 아님).

파일 배치:
```text
genre/ballad.md
genre/acoustic.md
genre/jazz.md
genre/trot.md
genre/rnb.md
genre/kpop.md
genre/indiepop.md

era/1960s.md
era/1970s.md
era/1980s.md
era/1990s.md
era/2000s.md
era/2010s.md
era/2020s.md

mood/warm.md
mood/moving.md
mood/hopeful-excited.md
mood/wistful.md
mood/uplifting.md
mood/energetic.md
```
구체적 리듬·성부·악기 진입 시점·보컬 프레이징·선율·다이내믹·제작 제약과 사용자 기존 음악 스타일은 각 MD에서 관리한다. 각 파일은 읽기 권한을 서버 프로세스 계정으로 한정한다.

설정된 비공개 디렉터리에서 필요한 파일이 없거나 길이가 비정상이라면 `src/music-style-library.mjs`가 실패하게 하며, 고객에게 내부 프롬프트를 반환하지 않는다. 개발 환경의 제네릭 기본값은 **실제 사용자 개인 레시피가 아니다**.

## 시대별 성공곡 분석의 근거 수집 프로토콜

- `1964~1983`: 멜론 시대별 가요 자료는 공식 안내에 따르면 **차트 순위가 아니라 인기곡을 가나다 순으로 모아 놓은 목록**이므로 1위/2위라고 주장하지 말 것.
- `1984~2004`: 멜론이 설명하는 뮤직박스(음반/테이프 판매 표본 + 방송빈도) 기반 시대별 차트. 정량 가중치와 원천의 편향을 보고 기록.
- `2010~현재`: 써클차트의 디지털/앨범 등 지표별 연도 순위. 여러 연도와 매체 지표는 동일한 척도라고 합치지 말 것. 써클차트 사이트는 허가 없는 AI/ML 학습·TDM을 금지한다고 표시하므로 자동 수집 전에 **별도 라이선스 검토**할 것.
- 각 `genre × era`마다 대표곡 선정 기준(연간 순위, 차트 종류, 발표 연도, 한국/해외 기준)과 원출처 URL을 별도 근거 레코드에 기록한다.
- 곡의 **장르·템포 범위·박자·악기 배치·구성 단계·조성 관계·가창 발성**을 일반적인 음악 요소로 추출하여 새로운 스타일을 설계한다. 특정 곡의 멜로디·후렴구·화성 진행 그대로의 모사, 원본 가사 복사, 실제 가수 음색 재현 지시는 하지 않는다.
- 서로 다른 장르 선택은 곡별로 다른 프롬프트를 만들고, **같은 장르 2곡**도 독립된 멜로디·편곡을 요구한다.
- 사용자 나이대는 **기억을 돕는 기본 추천에 한해** 활용한다. Krumhansl & Zupnick (2013)과 Renwick & Woolhouse (2023)는 청소년~초기 성인기 음악 회상이 두드러지는 경향을 보고하지만, 개인에게 한 시대만 강제하는 근거는 아니다. 고객이 명시적으로 선택한 시대는 연령 추정보다 우선.

## 원문 근거 (실제 원논문 및 원자료 안내)

1. Krumhansl, C. L., & Zupnick, J. A. (2013). *Cascading Reminiscence Bumps in Popular Music*. Psychological Science, 24(10), 2057–2068. DOI: 10.1177/0956797613486486 — https://pubmed.ncbi.nlm.nih.gov/24006129/
2. Renwick, J., & Woolhouse, M. H. (2023). *Reminiscence bump invariance with respect to genre, age, and country*. Psychology of Music, 51(4), 1349–1365. DOI: 10.1177/03057356221141735 — https://pubmed.ncbi.nlm.nih.gov/37484700/
3. 멜론 시대별 차트, 차트 생성 기준과 **1964~1983 인기곡 비순위 안내** — https://www.melon.com/chart/age/index.htm?chartDate=1990&chartGenre=KPOP&chartType=AG
4. 써클차트 공식 안내/디지털 차트 — https://circlechart.co.kr/
 
## 아직 충족되지 않은 작업

- 수십 년 × 모든 7개 장르의 정량적 실제 대표곡 전수 분석은 아직 수행되지 않았다. **제네릭 프롬프트를 이미 검증된 최고 인기곡 분석이라고 표시하면 안 된다.**
- 사용자가 이전에 요청했던 발성·악기·전개 지시는 노래별 조건이 다를 수 있어 *전체 노래에 일괄 적용하지 말고* 전용 장르/상황 프로필로 분리해야 한다.
- 운영 서버의 비공개 스타일 MD, 보호된 AI 작사 API, 결제 후 주문·가사 수정 DB, Suno 사업용 라이선스는 각각 별도의 검증 및 배포가 필요하다.
