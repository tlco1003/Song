# WITHU — 주문 7단계 / 비공개 작사 및 음악 스타일 실행 규격 (2026-11-06)

## 1. 사용자 페이지
- \`docs/create.html\` 7/7은 기존 입력(상대·사연·감사/사과·관계·말투·장르·분위기·시대)을 **텍스트로만** 최종 확인한다.
- 사용자에게 GPT 가사, 내부 작사 지시, 제작용 Suno 스타일 텍스트를 사전 표시하지 않는다.
- 생성 성공과 무관하게 \`checkout.html\` 상품(1곡·2곡·영상 견적) 및 장르 구성을 거쳐 \`payment.html\`로 이동한다.
- 결제 페이지에서 PG 결제 승인과 수령 이메일 발송은 **비활성 상태**다. 단순히 페이지가 열리는 것을 결제 완료로 오인하지 않는다.
- GitHub Pages에는 \`/api\` 서버가 없으므로 서버 초안 저장은 일어나지 않는다. 이 경우에도 사용자의 선택·상품·결제 페이지로 화면 이동은 정상 작동한다.

## 2. 비공개 서버 처리
- \`POST /api/commerce/drafts\`: 서버 배포 환경에서만 동작한다. **선택값과 사연만** 받고 검증하여 \`src/order-draft-preparation.mjs\`에서 비공개 작사 요청을 만든다.
- 서버 작사 지시의 기준은 \`src/lib.mjs\`의 \`buildLyricPrompt\`와 \`가사 프롬프트.md\` 정책 파일(운영 시 \`WITHU_PRIVATE_LYRIC_POLICY_FILE\`로 교체 가능)이다.
- \`src/music-style-library.mjs\`는 저장된 장르별·시대별·분위기별 정적 스타일을 선택/조합한다. **스타일 생성을 위한 별도 LLM 호출 없음.** 사업용 고유 시대·장르 레시피는 \`WITHU_PRIVATE_STYLE_DIR\`의 비공개 MD에 보관한다.
- 음악 스타일은 곡별로 **1,000자 이하 강제 검사**한다. 긴 프리셋은 자동 잘라내지 않고 실패 처리한다.
- \`src/private-draft-store.mjs\`는 \`WITHU_ORDER_DRAFT_DIR\`에 AES-256-GCM으로 암호화해 저장하며, **30분** 유효한 임의 식별자만 고객에게 돌려준다. 공개 HTML, 결제 요약, 브라우저 임시 저장소 또는 GitHub Pages에 실제 프롬프트를 넣지 않는다.
- \`src/paid-lyric-production.mjs\`는 **PG 승인 확인 및 결제 상태 검증 후에만** 비공개 지시문으로 AI 가사를 생성하여 보호된 주문 DB에 저장하도록 설계된 워커 계약이다.
- 구매 확정/DB 트랜잭션/결제 PG/이메일/음원 생성 API는 아직 연결되지 않았다. \`storeGeneratedLyricsAtomic\`는 실사업 운영 시 원자성/멱등성 보장이 필요한 별도 어댑터다.

## 3. 배포 전 필요 환경
- \`WITHU_ORDER_DRAFT_DIR\`: Git 저장소 및 정적 웹 루트 **밖**의 접근 제한된 서버 볼륨 (예: \`/srv/withu-private/drafts\`).
- \`WITHU_ORDER_DRAFT_ENCRYPTION_KEY\`: 32바이트 난수의 hex 문자열(정확히 64자리), 서버 비밀값 저장소로 주입. 예: Node \`crypto.randomBytes(32).toString('hex')\`로 운영자가 생성.
- \`WITHU_PRIVATE_STYLE_DIR\`: 운영자만 접근 가능한 비공개 음악 레시피 MD 디렉터리. 기존 \`genre/\`, \`era/\`, \`mood/\` 경로에 각각 선택 가능한 스타일 파일을 저장한다.
- \`WITHU_PRIVATE_LYRIC_POLICY_FILE\`: 별도 서버에 올린 비공개 작사 원칙 MD 파일 경로. 설정값이 있으면 파일이 없을 경우 시작 단계에서 실패한다.
- \`OPENAI_API_KEY\`: 서버에서만 보관. 검증된 결제 후에만 실제 가사 작업을 수행하도록 결제·저장 어댑터와 워커를 연결해야 한다.

## 4. 공개 소스 주의
현재 \`tlco1003/Song\` 자체가 **공개 GitHub 저장소**다. 저장소 안에 작성한 프리셋/작사 원칙은 GitHub에서 코드를 읽는 사람에게 보일 수 있다. HTTP 경로를 막는 것만으로 소스 보호가 되지 않는다. 사업용 고유 프롬프트는 반드시 비공개 저장소 또는 위 서버 외부 비밀 볼륨으로 이동하고, 공개 저장소에는 키/고유 프롬프트를 커밋하지 않는다.

## 5. 검증
- 7단계에서 선택 내용만 표시 / 가사 없더라도 8단계(상품 선택)로 이동.
- 1곡·2곡 장르 선택을 유지하면서 결제 페이지 이동. 영상 상품은 견적 전 PG 결제 차단.
- 스타일 1000자 초과 실패, 클라이언트가 제출한 \`stylePrompt\`/가사를 신뢰하지 않음.
- 서버 비공개 암호화 파일의 무결성/복호화 검증, 키 누락 시 503. 실제 결제 없는 가사 생성 금지.
