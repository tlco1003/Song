고객이 선택한 주문에만 완성곡과 가사를 연결하고, 발송된 링크와 추가 결제를 확인하는 작업 공간이에요.

운영 서버 연결 대기 · 관리자 로컬 시연

운영자 인증

고객 자료는 공개 GitHub에 올라가지 않아요. 현재 이 관리 도구는 로컬 테스트 서버의 보호된 API에만 연결돼요.

비공개 주문 서버를 연결하면 이곳에서 주문과 고객 제작물을 관리할 수 있어요.

01 · NEW ORDER

테스트 고객 주문 생성

실제 결제는 청구하지 않는 로컬 시연입니다. 고객 연락처는 운영 DB 연동 전까지 시험값만 사용하세요.

02 · CUSTOMER ORDERS

고객별 주문함

주문번호와 수신 이메일을 기준으로 음원과 가사가 구분돼요. 관리자 키가 검증되기 전에는 아무 정보도 나타나지 않아요.

아직 연결된 고객 주문이 없습니다.
03 · SONG PRODUCTION

선택된 고객의 음원과 가사 등록

고객 주문을 선택하세요.

실제 PG 결제가 아닌 로컬 테스트입니다.
04 · MAIL & LINK

고객에게 보낼 메일과 링크

메일 디자인을 확인하거나, 로컬 모의 발송함에서 고객별 개인 링크를 열어볼 수 있어요.

실제 메일 디자인 미리보기고객 노래함 시연
05 · OPTIONAL DOWNLOAD

추가 10,000원 결제 후 다운로드 화면

운영 환경에서는 상업적 이용 권리 확인과 별도의 PG 10,000원 결제가 있어야 원본 다운로드가 열려요.

실제 돈은 결제되지 않으며, 시험용 접근 권한만 부여돼요.

이 페이지의 폼은 시연용입니다. 라이브 고객의 실제 결제·음원과 연락처는 운영 서버 DB 및 비공개 저장소 연결 후에만 표시됩니다.
