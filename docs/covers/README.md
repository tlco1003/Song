업로드 대상: `docs/covers/` — **각 파일을 직접 업로드**해야 한다. ZIP을 그대로 업로드하면 사이트가 이미지 파일로 해석하지 못한다.

기존 원본 PNG에서 동일한 그림을 768×768 WebP로 변환해 한 번에 등록할 수 있는 ZIP 파일 `WITHU_8_covers_upload.zip`을 대화에서 제공한다. 고객 홈페이지는 `docs/media/tracks.json`의 `coverImage` 필드를 읽는다. 이미지가 아직 업로드되지 않았다면 레코드판 대신 간결한 색상 커버가 표시되며 네트워크 오류가 발생하지 않도록 한다.

## 기능 상태

- 홈 화면: 원곡별 정사각형 커버와 곡 카드 썸네일
- 미리 듣기/결제: 현재 선택한 예시곡의 커버 및 상세 재생 페이지 링크
- 고객 상세 페이지: `song.html?demo=song-...`는 누구나 볼 수 있는 **공개 예시**. 결제 고객 전용으로 꾸며서 개인정보를 노출하면 안 된다.
- 실제 결제 후 전달: 인증·기간 제한 전달 토큰과 보호된 저장소 API가 준비되기 전에는 활성화 금지.
- 커버 변경: JPG/PNG/WebP를 브라우저에서 1024×1024 WebP로 잘라 **IndexedDB에 기기 내 저장**. 다른 고객에게 게시되는 기능이 아니다.
- AI 이미지: `src/cover-image.mjs`와 `POST /api/covers/generate`가 운영자 인증 후 OpenAI API 호출을 처리할 수 있도록 준비됐다. API 키와 관리자 토큰이 없으면 사용 불가. 고객별 인증/과금/저장 기능은 별도 개발.
- 영상형 상품: 완성된 **오디오가 포함된 MP4**가 전달될 때만 영상 플레이어로 표시한다. 10초 무음 루프는 전체 뮤직비디오로 간주하지 않는다.

## 경로 보안

GitHub Pages의 `song.html` 상세 화면은 **공개 예시**만 표시한다. 실제 고객 음원은 추측 가능한 `?demo=`나 `docs/media`에 올리지 말고 비공개 스토리지 및 인증된 만료 URL로 제공한다.
