HOW WITHU WORKS

복잡한 작곡 대신,
당신의 이야기부터.

어렵게 글을 쓰거나 노래를 잘 부를 필요는 없습니다. 간단한 질문에 답하면, WITHU는 사연에 담긴 관계와 감정의 흐름을 가사로 풀어내는 경험을 목표로 합니다.

01.

기억과 마음을 적어요

누구에게 보내나요? 그 사람과의 기억은 무엇인가요? 고맙거나 미안했던 일, 꼭 전하고 싶은 말을 적어요.

02.

편지 같은 가사를 만들어요

GPT를 활용해 상대의 마음을 헤아리고, 기억에서 깨달음으로 이어지는 가사를 다듬어요. 완성 전 직접 수정할 수 있어요.

03.

음악으로 마음을 전해요

선택한 장르와 분위기에 따라 선율과 편곡을 구상해요. Suno를 통한 서비스 자동 생성은 공식 상업용 API 제휴를 검토하고 있어요.
