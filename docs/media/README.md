# WITHU 공개 음악 업로드 폴더

이 폴더에 본인에게 공개·상업용 게시 권리가 있는 MP3를 업로드하면 WITHU 소개 사이트 음악 플레이어가 파일을 찾아 재생합니다.

기준곡 3개의 게시 파일명(대소문자 구분):
- `nara.mp3` = 〈나라는 사람〉 (4:17)
- `taehwan.mp3` = 〈구태환에게〉 (5:20)
- `jeongmi.mp3` = 〈내사랑김정미〉 (5:50)

그 외 MP3 파일도 GitHub 공개 저장소의 파일 목록 API로 자동 발견합니다. 파일 이름을 사람이 알아보기 쉽게 적으세요. GitHub Pages 배포에는 시간이 걸릴 수 있으며, 목록을 새로고침하면 반영됩니다.

**관리자 파일 게시:** https://github.com/tlco1003/Song/upload/main/docs/media

GitHub 웹 업로드는 파일 하나당 25 MiB까지 지원하는 것이 일반적입니다. 더 큰 파일은 별도 승인된 저장소/호스팅이 필요합니다.

**권리와 개인정보:** 공개된 음악에는 받는 사람의 실명과 개인적 이야기가 들어갈 수 있습니다. 제작자 상업 이용권, 등장하는 제3자의 공개 동의, 음성권·초상권을 반드시 확인하세요.

GitHub Pages에는 익명 고객의 파일을 안전하게 저장할 서버가 없습니다. 소개 사이트의 '내 파일 선택'은 현재 브라우저에서만 미리 듣는 기능이고 영구 게시가 아닙니다.
