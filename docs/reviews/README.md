# WITHU 실제 동영상 후기 게시

허락받은 **실제 사용자의 동영상 후기**만 이 폴더에 게시합니다.

1. 공개·보관 목적과 초상·음성 이용 동의를 명확히 받습니다.
2. MP4/WebM 파일을 `docs/reviews/`에 등록합니다.
3. `reviews.json`의 `reviews` 배열에 다음과 같이 등록해야만 표시됩니다.

```json
{"title":"후기 영상 제목","file":"real-review-001.mp4","consentConfirmed":true}
```

`consentConfirmed`는 **실제 동의가 확인되었을 때만** `true`로 설정합니다. 동의가 없는 영상·합성 영상을 실사용 후기라고 표시하지 않습니다.

GitHub Pages는 정적 사이트입니다. 방문자가 선택한 영상은 현재 브라우저에서만 미리볼 수 있고 영구 게시되지 않습니다. 고객별 업로드·동의 수집·관리자 승인·삭제는 인증된 서버를 별도로 구축해야 합니다.

공개 GitHub 저장소는 원본 영상과 삭제 이력을 보호할 수 없습니다. 실제 사용자 후기를 운영할 때는 별도 보안 저장소가 권장됩니다.
