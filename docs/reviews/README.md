# WITHU 실제 사용자 후기 영상

현재 실제 동의받은 후기 영상 파일은 제공되지 않았습니다. **가짜 후기는 게시하지 않습니다.**

리뷰 제공자의 사전 공개 동의와 초상·음성 사용 허락을 받은 본인 소유 MP4 / WebM 파일만 이 디렉터리에 올리세요. 사이트는 공개 저장소 파일 목록에서 실제 영상만 탐색해 재생합니다.

관리자 게시: https://github.com/tlco1003/Song/upload/main/docs/reviews

주의: 공개 GitHub 저장소의 파일은 누구나 열람·다운로드할 수 있으며, 삭제해도 Git 기록에 남을 수 있습니다. 어린이·제3자의 얼굴/목소리·성명·사생활이 포함되면 공개하기 전에 필요한 동의와 검수를 반드시 거치세요.

방문자 임의 업로드와 공개 후기는 가입·인증·저장소·검수·삭제 요청 처리 기능을 갖춘 별도 서버 구축 후 제공할 수 있습니다.
