MP4 파일이 화면에 안 나오는 경우

이 페이지의 <video>는 GitHub Pages에서 공개된 MP4가 있어야 자동으로 재생돼. 현재 GitHub Actions 결과물은 비공개 Artifact로 보관돼 있기 때문에 HTML만 게시한 상태에서는 자동 스트리밍되지 않아. 다른 영상으로 몰래 대체하지 않아.

  1. GitHub 비공개 실행 결과 ZIP 다운로드 (저장소 접근 권한 및 로그인 필요, 만료될 수 있음)
  2. 압축을 풀기 어려우면 비공개 GitHub 저장소에 영구 보존한 실제 v45 MP4 바로 열기 · v47 검증 불합격 MP4 바로 열기를 이용해. 비공개 저장소 접근 권한과 GitHub 로그인이 필요해.
  3. ZIP 압축 해제 후 NARA_V45_CANONICAL_3D.mp4와 NARA_V47_CANONICAL_3D_WITH_LEARNED_SKIN.mp4를 찾기
  4. 위의 각 파일 선택 버튼으로 지정하면 이 페이지에서 영상 재생과 나란히 비교가 가능해. 서버로 업로드하지 않음.
