아랫턱 피부의 이미지 이동량 MAE 3.6934px · 정적인 기준 5.7827px (낮을수록 좋음). 이 데이터만의 예측 프록시 검사 결과야.

실제 턱관절·하악골 회전각을 영상으로 측정했다고 주장하지 않아.

치아·입안은 아직 의료 분할이 아냐

구강 내부의 어두운 부분과 치아처럼 보이는 밝은 픽셀을 분리하는 실험을 했지만, 치열·혀의 정답 마스크가 없어 임상적 분할 정확도는 계산할 수 없어. 오므린 입술을 치아로 잘못 인식한 사례는 후보 검출에서 억제했어.

새로운 치아를 합성하거나, 실제 뼈가 움직이는 영상이라고 표시하지 않아.

한국어 발음 정답·가창 타임코드는 별도 검증 대상

정확한 모음별 음소 시간 라벨이 없는 영상을 정답으로 만들어 학습시키지 않았어. v27의 새 학습은 입 개방과 턱 영상 움직임에 한정되고, 한국어 발음·가사 시간 정렬은 독립적인 사람 검수 데이터를 요구해.
