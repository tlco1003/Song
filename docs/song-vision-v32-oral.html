02 · 분리한 구조

실제 확인 가능한 영역: 입술 외곽, 닫힘선, 어두운 구강 영역, 치아·혀 색상 후보, 볼·턱의 관찰 가능한 표면.

3D 구조 연결용 데이터: 고정 상악과 코, 관절로 움직이는 하악, 독립적인 윗입술·아랫입술, 좌우 볼·광대·피부, 가려지는 치아·혀.

후자의 실제 3D 뼈 위치와 보이지 않는 구강 구조는 아직 측정하거나 재구성하지 못했어.

03 · 한글 전체 발음 구조

초성 19개, 중성 21개, 종성 28개 슬롯과 11,172개 현대 한글 음절을 해체하는 코드를 만들었어. 모든 발음 정답을 학습했다는 의미는 아니야.

받침 발음 변화와 동화, 연음, 음소 시작/끝 시각을 정확하게 학습하려면 사람 검증 발음 라벨과 실제 음성의 정렬 데이터가 필요해.

04 · v32 품질 판정

구조 구현·영상 생성 완료 / 실제 3D 안면 학습과 정확한 립싱크는 미완료. 현재 어두운 구강 픽셀 검출은 입술의 전체 안쪽 경계에 대한 의료적 정답이 아니며, 치아·혀 분류는 색상 기반 미검증 후보야.

개인 얼굴의 3D 골격은 추측한 턱 회전각으로 만들지 않고, 실제 메쉬·회전 기준점·표정 랜드마크가 준비됐을 때 적용되도록 별도 인터페이스를 추가했어. 검증되지 않은 발음 라벨은 엔진에서 훈련 입력으로 거부해.
