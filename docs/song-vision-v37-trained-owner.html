03 · 학습한 것과 아직 못한 것

실제로 학습: 소리의 음향 특징에서 실제 영상의 입술 너비·높이, 입안 개방 후보, 턱끝 그림자 위치를 추정하는 모델. 3D 턱 회전과 입술 제어 엔진에도 값을 전달해.

연구용 제어값: 혀끝·혀날·혀몸통·혀뒤쪽·혀뿌리, 경구개·연구개, 치아와 자음 접촉, 후두 긴장·기식은 v35 조음 프리셋을 이용해 3D 움직임으로 연결했어.

아직 미완료: 네 실제 턱뼈의 3D 관절각, 피부 근육 힘, 보이지 않는 개인 혀의 위치, 음절별 검증된 음성인식 라벨, 자연스러운 완성형 가창 립싱크. 음성에서 혀 위치를 유일하게 계산할 수는 없어. 이를 학습 완료로 표시하지 않았어.

모음 분류 약지도 실험은 별도 20개 구간에서 사용자 제공 순서와 35% 일치했어. 독립된 발음 정답이 없으므로 이 수치는 공식 음성인식 정확도가 아니며, 음소를 자동 확정하는 기능은 꺼둔 상태야.
