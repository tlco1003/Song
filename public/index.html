BEFORE YOU BEGIN
개인 실험용 웹앱 안내
이 프로젝트는 로컬 전용 MVP입니다. 서버에 Gemini와 ElevenLabs API 키를 넣어야 실제 노래가 생성됩니다. 키를 넣지 않은 경우 버튼은 실패 사유를 안내하고 가짜 음원을 만들지 않습니다.
녹음 목소리는 음성 프로필 등록 시 ElevenLabs에 전송됩니다. 서버의 생성 음원은 기본 60분 동안 보관되고 자동 삭제됩니다. 제공업체 데이터는 별도의 삭제·보관 정책이 적용됩니다.
음성 변환은 가창 전문 AI 품질을 보장하지 않습니다. 개인 음색의 유사도, 한국어 발음과 고음 품질은 실제 음원을 들어 확인해야 합니다.
마이크 기능은 localhost 또는 HTTPS 환경이 필요합니다. 본인 목소리만 사용하고 공개 배포 전 사용자 인증·결제 제한·법적 검토를 완료하세요.
